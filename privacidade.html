Política de privacidade

Esta política explica quais dados o CentralBackup acessa quando conectado a uma conta Google e como eles são tratados.

Dados do Google que o app acessa

  • Permissão drive.file: apenas os arquivos e pastas criados pelo próprio CentralBackup no Google Drive (pasta "CentralBackup").
  • O endereço de e-mail da conta conectada, só para mostrar na tela qual conta está ligada.

O app não acessa nenhum outro arquivo do Drive, nem e-mails, contatos ou agenda.

Como os dados são usados

Os arquivos de backup são enviados ao Drive para guarda e, quando a equipe pede, compartilhados por link para download. O conteúdo dos backups já vai criptografado com senha (AES-256); a senha nunca é enviada ao Google.

Armazenamento e segurança

A autorização de acesso (token) fica guardada criptografada no servidor próprio da Aconect. Nenhum dado é vendido, cedido ou compartilhado com terceiros.

Como revogar

A qualquer momento: na tela de Configurações do CentralBackup ("Desconectar") ou em myaccount.google.com/permissions. Os arquivos que já estão no Drive continuam lá, sob controle do dono da conta.

Uso de dados do Google (Limited Use)

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
